# Calfluent

Static landing page for [calfluent.com](https://calfluent.com), published with GitHub Pages from `main`.

- `index.html`: the landing page; `privacy.html`: the privacy note.
- `styles.css`: the whole design system (tokens at the top of the file).
- `script.js`: sets the footer year and starts the hero illustration once it is on screen.
- `assets/`: local images. `social-card.png` is rendered from `social-card.svg`.

No build step is required. Keep the `CNAME` file as it is: it holds the custom domain.
